# IPTV-MITV3

Ứng dụng IPTV tối giản tối ưu riêng cho Xiaomi Mi TV 3 60".

## Mục tiêu
- Android 5.1 / API 21+
- ExoPlayer 2.19.1
- SurfaceView
- Ưu tiên hardware decoder
- 1080p tối đa 60 fps khi decoder firmware hỗ trợ
- Mở URL M3U/M3U8/MPD/direct stream
- Mở file M3U từ bộ nhớ/USB
- Lưu playlist theo tên trong bộ nhớ riêng của app
- Tự nạp lại playlist dùng gần nhất
- Theo dõi decoder thật và dropped frames
